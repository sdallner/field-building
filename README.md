# Field Monitor prototype

Snapshot of the Field Monitor viewer for the Institutional Breakthroughs project (MLD-371): a daily digest of launches, funding, open calls, policy moves and research in R&D for AI-era institutions. Starter issue, data as of 8 October 2026.

`index.html` is self-contained (all data embedded) and is served with GitHub Pages.

Suggested tour: Digest → Open calls → All items (open "Why this ring") → Field map.
